## 📖 Sobre o projeto

A **Página de Login com Animação** é uma interface web estática desenvolvida com HTML5 e CSS3. O projeto apresenta um formulário de login moderno, acompanhado por uma imagem ilustrativa e por animações visuais suaves.

Seu objetivo é demonstrar conhecimentos em estruturação de páginas, estilização, responsividade e animações utilizando somente tecnologias nativas do navegador, sem frameworks ou bibliotecas JavaScript.

O layout é dividido em duas áreas: uma seção visual com a ilustração e outra destinada ao formulário. Em telas menores, a interface é adaptada por meio de Media Queries.

> Este projeto demonstra a camada visual de uma página de login. Não há autenticação, validação com JavaScript ou integração com backend na versão atual.

## ✨ Funcionalidades

- Página de login com interface moderna;
- campos para usuário e senha;
- botão de login estilizado;
- animação de hover no botão;
- transições suaves implementadas com CSS;
- layout dividido entre imagem ilustrativa e formulário;
- interface responsiva;
- compatibilidade com navegadores modernos em computadores e dispositivos móveis;
- tipografia carregada pelo Google Fonts.

## 🚀 Tecnologias

- **HTML5:** estrutura e conteúdo da página;
- **CSS3:** estilização, layout, transições e animações;

- **Google Fonts:** carregamento da tipografia utilizada no projeto.

## ⚙️ Como executar

### Clonar o repositório

```bash
git clone https://github.com/archivesysl/loginwithanimation.git
cd loginwithanimation
```

### Abrir localmente

O projeto não exige instalação de dependências, servidor local ou processo de build.

Para executar:

1. Localize o arquivo `index.html` na pasta clonada;
2. abra o arquivo em qualquer navegador moderno.

Também é possível abrir o projeto pelo terminal do Windows:

```powershell
start index.html
```

## 📂 Estrutura do projeto

O projeto possui uma estrutura pequena, separando a marcação da página e sua apresentação visual:

```text
.
├── index.html
├── style.css
└── README.md
```

- `index.html`: estrutura da página e do formulário de login;
- `style.css`: estilos, responsividade, transições e animações;
- `README.md`: documentação do projeto.

## 🌐 Deploy

Por ser uma página estática, o projeto pode ser hospedado no GitHub Pages, Vercel, Netlify ou em qualquer servidor web capaz de entregar arquivos HTML e CSS.

Também pode ser executado integralmente em ambiente local, sem instalação de dependências, bastando abrir o arquivo `index.html` em um navegador moderno.
